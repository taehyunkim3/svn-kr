# TestFlight Beta App Review Information

## Sign-in Required

No. SVN for Mac does not require an app account.

## Review Notes

SVN for Mac includes an in-app sample project so the main features can be reviewed without an SVN server or account.

1. Launch the app.
2. In the initial Add SVN Repository window, click **Browse Sample Project**.
3. Select **Atlas Mobile** in the sidebar.
4. Review the Changes, Files, and Commit History tabs.

The sample project contains local changes, text diffs, a working-copy file tree, repository locks, remote changes, and commit history. Demo mode does not access UserDefaults project data, Keychain credentials, local working folders, or an SVN server. Use **Exit Demo** in the toolbar to return to normal mode.
