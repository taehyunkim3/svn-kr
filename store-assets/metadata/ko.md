# App Store 메타데이터 — 한국어

## 앱 이름

SVN Mac

## 부제

가볍고 안전한 SVN 클라이언트

## 프로모션 문구

여러 SVN 작업 폴더의 변경 사항, diff, 커밋 기록과 로컬 리비전 위치를 하나의 macOS 네이티브 앱에서 확인하세요.

## 설명

SVN Mac은 여러 Subversion 작업 폴더를 한곳에서 관리하는 macOS 네이티브 클라이언트입니다.

복잡한 명령을 외우지 않아도 로컬 변경 사항 확인부터 파일별 diff, 선택 커밋, 업데이트와 서버 커밋 기록 조회까지 일상적인 SVN 작업을 처리할 수 있습니다.

주요 기능

• 저장소 URL을 입력해 새로운 작업 폴더 체크아웃
• 기존 SVN 작업 폴더를 여러 개 등록하고 빠르게 전환
• 수정·추가·미추적 파일 상태 확인
• 파일별 텍스트 diff 확인
• 필요한 파일만 선택해 커밋
• 서버 최신 리비전과 내 로컬 리비전 위치 비교
• 작성자, 시간, 변경 경로가 포함된 최근 커밋 기록
• 서버 커밋, 로컬 기준과 미커밋 변경을 보여주는 타임라인
• 프로젝트별 SVN 사용자명과 macOS Keychain 비밀번호 관리
• 한국어와 영어 인터페이스
• 커밋 시각 표시 시간대 선택

SVN 실행에 필요한 도구와 라이브러리가 앱에 포함되므로 Homebrew나 별도의 SVN 설치 없이 사용할 수 있습니다.

비밀번호는 앱 설정 파일에 기록하지 않고 macOS Keychain에 저장합니다. SVN 서버 연결은 사용자가 등록한 저장소 주소로 직접 이루어집니다.

## 버전 0.4.1 출시 노트

• App Sandbox 환경에서 선택한 폴더로 체크아웃하지 못하던 문제 수정
• 자체 서명 또는 호스트명이 다른 SSL 인증서를 저장소별로 허용하는 옵션 추가
• 현재 SVN 작업 폴더를 Finder에서 바로 여는 버튼 추가
• 미추적 파일 선택 시 diff 오류 대신 상태 안내 표시
• 한글 커밋 메시지의 마지막 글자가 누락될 수 있는 문제 수정
• 커밋 완료 후 메시지 초기화 및 창 활성화 시 자동 새로고침 추가
• 혼합 리비전 작업 사본의 업데이트 필요 상태를 실제 서버 변경 기준으로 판정
• App Store 패키지에 남을 수 있는 quarantine 확장 속성 제거
