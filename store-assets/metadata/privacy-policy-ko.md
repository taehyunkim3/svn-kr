# SVN for Mac 개인정보 처리방침

최종 수정일: 2026년 7월 16일

SVN for Mac은 사용자가 등록한 SVN 저장소와 로컬 작업 폴더를 관리하기 위한 macOS 애플리케이션입니다.

## 수집하는 정보

SVN for Mac 개발자는 앱을 통해 개인정보, 사용 분석 정보 또는 광고 식별자를 별도로 수집하지 않습니다.

사용자가 입력한 SVN 사용자명은 앱의 로컬 설정에 저장될 수 있습니다. 비밀번호는 macOS Keychain에 저장되며 앱 설정 파일에는 기록되지 않습니다.

## 네트워크 통신

앱은 사용자가 직접 등록한 SVN 서버와 통신합니다. 해당 통신 과정에서 처리되는 계정 정보, 저장소 데이터와 로그에는 해당 SVN 서버 운영자의 정책이 적용됩니다.

## 데이터 공유

SVN for Mac 개발자는 앱을 통해 사용자 데이터를 수집하거나 제3자에게 판매 또는 공유하지 않습니다.

## 데이터 삭제

앱에서 작업 폴더 등록을 제거할 수 있으며 저장된 비밀번호는 macOS Keychain에서 삭제할 수 있습니다. 앱 삭제 후 남은 Keychain 항목은 macOS의 Keychain Access에서 직접 삭제할 수 있습니다.
