# 임시 파일 표시와 전체 선택 제외 설계

## 목표

SVN 변경 목록에는 흔한 애플리케이션 임시 파일을 계속 표시하되 상태를 `임시파일`로 구분한다. 사용자가 `전체 선택`을 누르면 이 항목들은 자동 선택하지 않지만, 행의 체크박스로 직접 선택해 커밋할 수 있다. `선택 해제`는 임시 파일을 포함한 모든 선택을 해제한다.

## 임시 파일 판정

오탐을 줄이기 위해 SVN 상태가 `unversioned`인 일반 항목 중 마지막 경로 구성 요소가 다음 패턴에 해당할 때만 임시 파일로 판정한다.

- Office 잠금 파일: `~$*`
- macOS 메타데이터: `.DS_Store`, `._*`
- 편집기 교환·백업 파일: `*.swp`, `*.swo`, `*~`, `#*#`, `.#*`

`*.tmp`와 `*.temp`는 실제 관리 대상일 수 있어 기본 패턴에 포함하지 않는다. 이미 SVN이 관리하는 항목은 파일명이 패턴과 일치해도 임시 파일로 재분류하지 않는다.

## 구조와 동작

임시 파일 여부는 경로와 SVN 상태를 입력받는 순수 판정 로직으로 제공한다. UI와 선택 로직이 같은 판정을 사용해 표시와 동작이 어긋나지 않게 한다.

`ProjectStore.selectableStatusPaths`는 수동 선택과 커밋 검증을 위해 현재 의미를 유지한다. 별도의 전체 선택용 경로 집합은 선택 가능한 상태 중 임시 파일만 제외한다. `CommitControlsView`의 `전체 선택`은 이 새 집합으로 선택을 교체하고, `선택 해제`는 기존처럼 `selectedPaths.removeAll()`을 호출한다.

`ChangesView`는 임시 파일로 판정된 행의 상태 배지를 한국어 `임시파일`, 영어 `Temporary`로 표시한다. 행 체크박스와 컨텍스트 메뉴는 미추적 파일의 기존 기능을 그대로 유지한다.

## 경계 조건

- 임시 파일을 수동 선택한 뒤 새로고침해도 해당 경로가 여전히 선택 가능하면 선택을 보존한다.
- 임시 파일을 수동 선택한 상태에서 `전체 선택`을 누르면 전체 선택 결과로 교체되므로 임시 파일 선택은 해제된다.
- 디렉터리는 파일명 패턴과 우연히 일치해도 임시 파일로 분류하지 않는다.
- 대소문자를 바꾸면 다른 이름인 Unix/SVN 경로 특성을 따라 패턴 비교는 대소문자를 구분한다.

## 테스트

- 각 내장 패턴과 비해당 경로를 순수 판정 테스트로 검증한다.
- `unversioned` 파일만 임시 파일이 되며 관리 파일과 디렉터리는 제외되는지 검증한다.
- 전체 선택용 경로에는 일반 변경 파일이 포함되고 임시 파일이 제외되는지 검증한다.
- 임시 파일이 수동 선택 가능한 전체 선택 가능 집합에는 남는지 검증한다.
- 화면 소스 회귀 테스트로 `임시파일`/`Temporary` 배지와 전체 선택 전용 경로 사용을 확인한다.
- 전체 `swift test`를 실행해 기존 선택·커밋 동작의 회귀 여부를 확인한다.
