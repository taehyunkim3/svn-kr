# 로컬 최상위 리비전 문구 개선

## 목적

혼합 리비전 작업 복사본의 가장 높은 리비전을 나타내는 `내 로컬 최고` 문구를 자연스럽고 의미가 분명한 표현으로 바꾼다.

## 변경 범위

- 커밋 기록의 배지와 범례에서 `내 로컬 최고`를 `내 로컬 최상위`로 변경한다.
- 도움말에서 `내 로컬의 최고 리비전`을 `내 로컬의 최상위 리비전`으로 변경한다.
- 영문 표현은 `My local maximum`과 `your local maximum revision` 대신 `Highest local revision`과 `your highest local revision`을 사용한다.
- 단일 리비전 작업 복사본의 `내 로컬 기준` 문구와 리비전 계산 로직은 변경하지 않는다.

## 검증

- 저장소 전체에서 기존 한국어·영문 문구가 남아 있지 않은지 검색한다.
- `swift test`를 실행해 회귀가 없는지 확인한다.
