## 위임 규칙 (사용자 지시)
- **`master` 머지는 이 저장소에서 매번 묻지 않고 진행해도 된다.** 2026-08-26 지시. 배포를 사용자가
  직접 하기 때문이다. **`push`는 여전히 금지**이고 태그·배포도 사용자 몫이다. 검수 책임은 그대로다 —
  게이트를 직접 돌려 통과를 확인한 뒤 머지한다.
- **agy** — 코드 수정 금지(읽기 전용만). 더불어 orca CLI가 `agy`를 에이전트로 받지 않는다
  (`Unknown TUI agent "agy"`). 실질적으로 위임 대상은 codex와 cursor 둘이다.
- **claude** — 사용자가 명시적으로 지목하지 않으면 하위 에이전트로 쓰지 않는다. 비용 때문.

## 이번 세션에 끝낸 것
- `LocalizationKey.allCases`를 타입 참조 배열로 복구 (`6cf5210`). 663줄 문자열 런타임 `split`이
  사라졌다. 단일 663원소 배열 리터럴은 **런타임 stack overflow**(`Thread stack size exceeded`)를
  내므로 그룹별 `private static let` 배열 + `flatMap`으로 쪼개져 있다. 생성기가 그 형태를 낸다.
  다시 하나로 합치지 마라.
- 사이드바 충돌 뱃지에 속성 전용 충돌 포함 (`278bade`).
- `.alwaysLockAndOpen` 정책에서 타 사용자 잠금 파일은 확인 창을 띄운 뒤 열도록 변경 (`278bade`).
  사용자 결정이다. 경고만 하고 **열기 자체는 막지 않는다.** 본인 잠금은 그대로 즉시 열린다.
- 무시 규칙 디렉터리 절대경로 상대화 (`svncore-accuracy` 머지). 기존 public 시그니처는 유지했고
  내부 오버로드를 추가했다.
- `hdiutil detach` 정리 실패를 0.5초 간격 3회 재시도 후 경고로 격리 (같은 머지).
- `Docs/SVNArgumentRules.md` 미확인 칸 20개를 실 svn 1.14.5로 전부 확정 (`c696fba`).
- 조사 보고서 2건: `Docs/audit/2026-08-26-recovery-entry-investigation.md`,
  `Docs/audit/2026-08-26-test-suite-audit.md`.

## 진행 중
`recovery-reachability-repro` — 「제자리 정리 불가(`canRepairCanonicalAliases == false`)인데
`recoveryPreview().blockingPaths`는 비어 있는」 작업 복사본이 실제로 만들어지는지 재현한다.
- 존재하면 새 작업 폴더 복구 시트에 진입점을 붙일 근거가 된다. 진입점 위치 후보는 조사 보고서의
  후보 B(프로젝트 머리글 또는 앱 메뉴)다. 후보 A(충돌 행)는 위 금지 대상이다.
- 존재하지 않으면 시트는 영구 도달 불가이고, 그 사실을 테스트로 고정한다.
- 브리프에서 **UI 진입점 붙이는 것은 금지**했다. 붙이려면 새 지역화 키가 필요해 생성기·리소스와
  충돌한다. 재현 결과를 받고 별도로 지시할 일이다.

## 작업 절차
1. 브리프에 **허용 파일 목록**을 명시하고, 타입 정의 파일까지 `grep -rl`로 확인해 포함시킨다.
   시그니처를 바꾸는 작업은 정의·호출·테스트가 한 묶음이다.
2. **병렬로 띄울 때 같은 파일을 두 에이전트에게 주지 않는다.** 이번 세션은 모듈로 갈랐다
   (SVNCore / SVNMac / 문서 / 읽기 전용 조사). 지역화 생성기와 `LocalizationKey.swift`는
   한 번에 한 작업만 만질 수 있다. 새 문구가 필요한 UI 작업은 그 작업과 병렬 금지다.
3. 게이트: `swift build` 무경고, `swift test` 기준선 이상 전부 통과, 허용 목록 밖 변경 0,
   **회귀 테스트가 수정을 되돌렸을 때 실제로 실패하는지 확인**하고 실패 메시지를 보고에 붙이게 한다.
4. **머지 중에는 `swift test`를 돌리지 마라.** 이번에 머지가 실행 중인 테스트의 트리를 바꿔
   결과를 버렸다. 머지를 다 끝낸 뒤 한 번 돌린다.
5. 완료 통보는 조정자 터미널 핸들로 받되 폴백을 브리프에 박는다. 이번에 cursor 쪽 통보가
   `agent_prompt_stalled`로 실패했고 `DONE-<이름>.md` 파일 폴백이 실제로 쓰였다.
6. 정리는 머지 직후 그 자리에서 한다. `git log --oneline master..<브랜치>`가 비고
   미커밋 변경이 없는 것을 확인한 뒤 `orca terminal stop` → `orca worktree rm --force`.
