저장소 탐색(`RepositoryBrowserView`)은 `AddRepositoryView`의 「저장소 찾아보기」에 배선되어 있다. 이전 사고(화면만 있고 진입점 없음)는 현재 코드에서 재발하지 않았다.

## 확인하지 않은 것

- 앱 GUI를 띄우지 않았다. 시트 충돌·Return 기본 동작·키 문자열 노출은 모두 **코드 기준 추정**이다.
- `Localizable.xcstrings`가 빌드 때 lproj로 합쳐지는지는 `.build` 산출물을 보지 못했다. `AppLanguage`가 lproj를 직접 연다는 점만 근거로 삼았다.
- `%1$@`/`%2$@` 순서만 다른 문구(`ui.bulk.unlock.partial.failure.details.71a6c5e8`, `ui.showing.first.commits.of.total.8d6f4a21`)는 positional specifier라 버그로 보지 않았다.
- 리소스에만 있고 화면이 안 쓰는 키 8개(`ui.folder.credentials.b4bd68eb` 등)는 예전 라벨로 보이며, 사용자 증상은 없다.
- `file://` 저장소로 시트 스택을 재현하지 않았다. GUI 없이 SwiftUI 시트 충돌을 확인할 수 없다.
- `svn` 인자·이스케이프·peg revision은 브리프 제외 범위라 보지 않았다.
